# GTD del Proyecto (Get Things Done)

Este sistema organiza el trabajo para que cualquier agente humano/IA pueda continuar sin contexto previo.

## Flujo diario
1. Captura todo en `00_INBOX.md`.
2. Define acciones concretas en `10_NEXT_ACTIONS.md`.
3. Mueve lo que se esta ejecutando a `20_IN_PROGRESS.md`.
4. Si algo se traba, registralo en `30_BLOCKED.md`.
5. Al cerrar tareas, registrar en `40_DONE.md`.
6. Bugs nuevos o confirmados: `50_BUG_HISTORY.md`.
7. Decisiones tecnicas y tradeoffs: `60_DECISIONS.md`.
8. Comandos y runbook: `70_RUNBOOK.md`.
9. Revision semanal: `80_WEEKLY_REVIEW.md`.

## Reglas
- Siempre anotar fecha (`YYYY-MM-DD`) y responsable.
- Cada item debe incluir criterio de cierre.
- No borrar historial; mover a `40_DONE.md` o marcar como cancelado.
