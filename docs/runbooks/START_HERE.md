# Start Here

Si eres un agente nuevo en este proyecto, sigue este orden:

1. Lee `README.md`.
2. Revisa `docs/handoff/PROJECT_HANDOFF_2026-04-24.md`.
3. Abre `gtd/10_NEXT_ACTIONS.md` para elegir el siguiente bloque de trabajo.
4. Mueve la tarea elegida a `gtd/20_IN_PROGRESS.md`.
5. Al terminar, registra en `gtd/40_DONE.md` y `gtd/50_BUG_HISTORY.md` si aplica.

## Criterio minimo antes de empezar cambios
- Backend responde `GET /api/health`.
- Frontend responde en `http://localhost:5173`.
- El contexto y decisiones recientes estan leidos.
